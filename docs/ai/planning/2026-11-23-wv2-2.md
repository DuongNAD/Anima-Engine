## Summary

`WV2-2` (Card 3 of [the World v2 design](../design/2026-11-20-world-v2-design.md)) implements Stages `S4`, `S6`, `S7`, `S8`, and `S9`, the memory-lean `4096²` multigrid generator pipeline, the `anima-worldgen` CLI, and the Card 3 invariant test suite inside [`anima-worldgen`](../../../src-tauri/crates/anima-worldgen/Cargo.toml), with zero changes to `src-tauri/src/`.

1. **Core Stages (`S4`, `S6`, `S7`, `S8`, `S9`):**
   - **Deposition (`src/deposition.rs`, `S4`):** Alluvial fans, Howard-Knutson meander floodplains, and DeltaRCM coastal deltas (synthetic upland micro-pond stamping removed in `8_MSG` rework).

   - **Biomes (`src/biomes.rs`, `S8`):** Continuous `C^2` 22-biome blending (`BiomeId`), domain warp, cirque glaciers, and Werner aeolian dunes.
   - **Caves (`src/caves.rs`, `S9`):** Karst and basalt caves emitting `cave_mask` and `cave_network.bin` (`ANMC` v1 LE binary).
2. **Lean `4096²` Pipeline & CLI (`src/pipeline.rs`, `src/bin/anima-worldgen.rs`):**
   - Multigrid progression (`512² -> 1024² -> 2048² -> 4096²`) spilling layers to disk with `raw_meta.json`, plus memory-lean `S1`/`S2`/`S3`/`S5` paths (including `erode_fluvial_step_f32_lean` eliminating `h_trial` via `swap(&mut h_t, &mut h_next)`).
3. **Tests & Target Policy (`tests/wv2_2_climate_biome_cave_tests.rs`, `tests/wv2_1b_solver_hydro_tests.rs`, `examples/wv2_2_release_verify.rs`):**

## Fastscape-SD Solver Contract (`WV2-1c` Carry-Over Notes `N1` & `N2`)

Carried forward from [the `WV2-1c` card note](./2026-11-20-wv2-1c.md) for [`erosion_fluvial.rs`](../../../src-tauri/crates/anima-worldgen/src/erosion_fluvial.rs):

- **Sweep-budget wall-time scaling (`N2`):** `FluvialParams::max_total_sweeps` (default `DEFAULT_MAX_TOTAL_SWEEPS = 4_096`) bounds the **count of Gauss-Seidel sweeps** spent across Phase A (receiver-first full-`dt` fast path) and Phase B (in-place upstream-to-downstream fallback with adaptive `dt` halving), not wall-clock duration. Because each sweep traverses all `N` cells of the D8 DAG, the elapsed time before `FluvialError::NonConvergence { budget_exhausted: true, .. }` is returned grows proportionally with grid size `N` (`4096²` performs `64x` the per-sweep work of `512²`). Callers running large grids must size `max_total_sweeps` and `dt_yr` knowing that a fixed sweep cap bounds iteration count, not constant wall-clock time.
- **Dry-zone timestep sizing (`N2`):** Dry and arid rain-shadow zones (precipitation near `min_precip_m_yr`, producing large local deposition coupling `beta_i = G * dx^2 / A_tilde_i`) typically fail Phase A convergence and fall back to Phase B adaptive `dt_yr` halving (up to `MAX_ALLOWED_DT_HALVINGS = 12`, `4,096` substeps). Excessively large `dt_yr` triggers deep halving cascades that exhaust `max_total_sweeps` quickly, so dry zones require a **moderate `dt_yr`** to converge cleanly well within the sweep budget.
- **Phase A budget enforcement & non-mutation (`N1`):** Both Phase A and Phase B check `sweeps_spent >= params.max_total_sweeps` before executing each sweep; exhausting the budget in either phase returns `Err(FluvialError::NonConvergence { budget_exhausted: true, total_sweeps, .. })` with `total_sweeps <= max_total_sweeps` and leaves the input elevation slice `h` unmodified. Phase A's share of the budget is pinned by `phase_a_sweep_budget_halts_loudly_without_mutating_h` in [`wv2_1b_solver_hydro_tests.rs`](../../../src-tauri/crates/anima-worldgen/tests/wv2_1b_solver_hydro_tests.rs) (humid 64-node chain at `nu = 1.0`, `dt_yr = 10_000.0`, `max_total_sweeps = 5`).
