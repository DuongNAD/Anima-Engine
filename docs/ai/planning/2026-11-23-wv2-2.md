## Fastscape-SD Solver Contract (`WV2-1c` Carry-Over Notes `N1` & `N2`)

Carried forward from [the `WV2-1c` card note](./2026-11-20-wv2-1c.md) for [`erosion_fluvial.rs`](../../../src-tauri/crates/anima-worldgen/src/erosion_fluvial.rs):

- **Sweep-budget wall-time scaling (`N2`):** `FluvialParams::max_total_sweeps` (default `DEFAULT_MAX_TOTAL_SWEEPS = 4_096`) bounds the **count of Gauss-Seidel sweeps** spent across Phase A (receiver-first full-`dt` fast path) and Phase B (in-place upstream-to-downstream fallback with adaptive `dt` halving), not wall-clock duration. Because each sweep traverses all `N` cells of the D8 DAG, the elapsed time before `FluvialError::NonConvergence { budget_exhausted: true, .. }` is returned grows proportionally with grid size `N` (`4096²` performs `64x` the per-sweep work of `512²`). Callers running large grids must size `max_total_sweeps` and `dt_yr` knowing that a fixed sweep cap bounds iteration count, not constant wall-clock time.
- **Dry-zone timestep sizing (`N2`):** Dry and arid rain-shadow zones (precipitation near `min_precip_m_yr`, producing large local deposition coupling `beta_i = G * dx^2 / A_tilde_i`) typically fail Phase A convergence and fall back to Phase B adaptive `dt_yr` halving (up to `MAX_ALLOWED_DT_HALVINGS = 12`, `4,096` substeps). Excessively large `dt_yr` triggers deep halving cascades that exhaust `max_total_sweeps` quickly, so dry zones require a **moderate `dt_yr`** to converge cleanly well within the sweep budget.
- **Phase A budget enforcement & non-mutation (`N1`):** Both Phase A and Phase B check `sweeps_spent >= params.max_total_sweeps` before executing each sweep; exhausting the budget in either phase returns `Err(FluvialError::NonConvergence { budget_exhausted: true, total_sweeps, .. })` with `total_sweeps <= max_total_sweeps` and leaves the input elevation slice `h` unmodified. Phase A's share of the budget is pinned by `phase_a_sweep_budget_halts_loudly_without_mutating_h` in [`wv2_1b_solver_hydro_tests.rs`](../../../src-tauri/crates/anima-worldgen/tests/wv2_1b_solver_hydro_tests.rs) (humid 64-node chain at `nu = 1.0`, `dt_yr = 10_000.0`, `max_total_sweeps = 5`).

### Step 0: 1-D Column Test (Script & Verbatim Output)

Per verdict brief `21_MSG`, before writing any 2-D code we built a 1-D column channel using the exact Phase A coupled Gauss–Seidel `Fastscape-SD` equation from [`erosion_fluvial.rs`](../../../src-tauri/crates/anima-worldgen/src/erosion_fluvial.rs) (`n = 1.0`, `m = 0.45`, `K_CAP = 0.22 * 2.2e-5 = 4.84e-6`, `K_SHALE = 1.00 * 2.2e-5 = 2.20e-5`) and the exact unmodified waterfall detector from [`lakes_falls.rs:1564-1672`](../../../src-tauri/crates/anima-worldgen/src/lakes_falls.rs) (`lith[lip] == CAP`, single-link upstream slope `S_up = (h[lip+1] - h[lip]) / dx < 0.08`, best drop within `<= 30 m` `>= 12.0 m`).

```python
#!/usr/bin/env python3
"""
WV2-2-PHYS Step 0: 1-D Fastscape-SD column test on horizontal caprock-over-shale strata.
Matches:
  - Solver: crates/anima-worldgen/src/erosion_fluvial.rs (step_fastscape_sd_dag, Phase A coupled GS)
  - Detector: crates/anima-worldgen/src/lakes_falls.rs:1564-1672
    (lithology_id[lip] == SandstoneCaprock, up_slope = (h[lip+1]-h[lip])/dx < 0.08,
     best_drop = max_{1<=k<=floor(30/dx)}(h[lip] - h[lip-k]) >= 12.0 m)
"""
from __future__ import annotations

K_SCALE = 2.2e-5
K_CAP = 0.22 * K_SCALE       # SandstoneCaprock: 4.84e-6
K_SHALE = 1.00 * K_SCALE     # SoftShale:        2.20e-5
M_EXP = 0.45
N_EXP = 1.0
MAX_DROP_RUN_M = 30.0
MIN_DROP_M = 12.0
MAX_UP_SLOPE = 0.08


def make_profile(N: int, dx: float, A_in_m2: float, s0: float = 0.015):
    """Cell 0 = fixed outlet (h=0); cell i drains to i-1; cell N-1 = upstream inlet."""
    x = [i * dx for i in range(N)]
    h = [s0 * xi for xi in x]
    # Upstream drainage area increasing downstream from A_in_m2 at N-1 (nu = 1.0).
    A_tilde = [A_in_m2 + (N - 1 - i) * 5.0 * dx * dx for i in range(N)]
    return h, A_tilde


def eval_lith_k(h: list[float], z_c: float, T: float, capped_top: bool) -> list[float]:
    """
    Horizontal stratum with base at advected datum z_c = z_c0 + U*t:
      - SoftShale below z_c (z_rel < 0)
      - SandstoneCaprock in [0, T) (or all z_rel >= 0 when capped_top=True)
      - SoftShale above T (when capped_top=False)
    """
    out = []
    for hi in h:
        z_rel = hi - z_c
        if capped_top:
            out.append(K_CAP if z_rel >= 0.0 else K_SHALE)
        else:
            out.append(K_CAP if 0.0 <= z_rel < T else K_SHALE)
    return out


def step_fastscape_sd_1d(
    h: list[float],
    A_tilde: list[float],
    K: list[float],
    U: float,
    dx: float,
    dt: float,
    G: float,
    tol: float = 1e-8,
    max_iters: int = 256,
) -> tuple[list[float], int]:
    """Exact 1-D analog of erosion_fluvial.rs Phase A coupled Gauss-Seidel (n=1, local term included)."""
    N = len(h)
    dx2 = dx * dx
    h_t = h[:]
    h_next = h[:]
    alpha = [K[i] * (A_tilde[i] ** M_EXP) * dt / dx for i in range(N)]
    beta = [G * dx2 / A_tilde[i] for i in range(N)]

    iters = 0
    for it in range(1, max_iters + 1):
        iters = it
        phi_in = [0.0] * N
        for k in range(N - 1, 0, -1):
            net_vol = (h_t[k] + dt * U - h_next[k]) * dx2
            phi_in[k - 1] += net_vol + phi_in[k]

        max_delta = 0.0
        h_next[0] = 0.0
        for i in range(1, N):
            target_free = h_t[i] + dt * U
            dep_up = (G / A_tilde[i]) * phi_in[i]
            updated = (target_free * (1.0 + beta[i]) + alpha[i] * h_next[i - 1] + dep_up) / (
                1.0 + alpha[i] + beta[i]
            )
            diff = abs(updated - h_next[i])
            if diff > max_delta:
                max_delta = diff
            h_next[i] = updated
        if max_delta < tol:
            break
    return h_next, iters


def inspect_detector(h: list[float], K: list[float], dx: float) -> dict:
    """Measure exact lakes_falls.rs:1564-1672 waterfall detector criteria along the 1-D channel."""
    N = len(h)
    max_k = min(6, max(1, round(MAX_DROP_RUN_M / dx)))
    max_drop_all = 0.0
    best_valid = None
    best_cap_by_drop = None

    for i in range(1, N - 1):
        drop_i = 0.0
        dist = 0.0
        for step in range(1, max_k + 1):
            base = i - step
            if base < 0:
                break
            dist += dx
            if dist > MAX_DROP_RUN_M + 1e-3:
                break
            d = h[i] - h[base]
            if d > drop_i:
                drop_i = d
        if drop_i > max_drop_all:
            max_drop_all = drop_i

        if K[i] == K_CAP:
            up_slope = (h[i + 1] - h[i]) / dx
            if best_cap_by_drop is None or drop_i > best_cap_by_drop["drop"]:
                best_cap_by_drop = {"idx": i, "drop": drop_i, "up_slope": up_slope}
            if drop_i >= MIN_DROP_M and up_slope < MAX_UP_SLOPE:
                if best_valid is None or drop_i > best_valid["drop"]:
                    best_valid = {"idx": i, "drop": drop_i, "up_slope": up_slope}

    return {
        "max_drop_all": max_drop_all,
        "best_cap": best_cap_by_drop,
        "best_valid": best_valid,
        "passed": best_valid is not None,
    }


def fmt_res(r: dict) -> str:
    bc = r["best_cap"]
    bv = r["best_valid"]
    bc_s = f"{bc['drop']:5.2f}m @ S={bc['up_slope']:.4f} (i={bc['idx']:3d})" if bc else "none"
    if bv:
        return f"PASS  lip={bv['idx']:3d} drop={bv['drop']:5.2f}m S_up={bv['up_slope']:.4f}"
    return f"FAIL  (best_cap={bc_s})"


def run_case(
    T: float,
    G: float,
    reeval: bool,
    capped_top: bool,
    A_in_km2: float = 25.0,
    U: float = 6.0e-4,
    dx: float = 10.0,
    N: int = 250,
    dt: float = 20.0,
    t_total: float = 80_000.0,
    z_c0: float = 0.0,
    s0: float = 0.015,
) -> dict:
    h, A_tilde = make_profile(N, dx, A_in_km2 * 1e6, s0=s0)
    K_frozen = eval_lith_k(h, z_c0, T, capped_top)
    steps = int(round(t_total / dt))
    t = 0.0
    max_iters = 0
    for _ in range(steps):
        z_c = z_c0 + U * t
        K = eval_lith_k(h, z_c, T, capped_top) if reeval else K_frozen
        h, iters = step_fastscape_sd_1d(h, A_tilde, K, U, dx, dt, G)
        max_iters = max(max_iters, iters)
        t += dt
    K_end = eval_lith_k(h, z_c0 + U * t, T, capped_top) if reeval else K_frozen
    res = inspect_detector(h, K_end, dx)
    res["S_cap_eq"] = (1.0 + G) * U / (K_CAP * (A_tilde[N // 2] ** M_EXP))
    res["max_iters"] = max_iters
    return res


def upsample_linear_1d(h_c: list[float], dx_c: float, dx_f: float) -> list[float]:
    ratio = int(round(dx_c / dx_f))
    Nf = (len(h_c) - 1) * ratio + 1
    hf = [0.0] * Nf
    for i in range(Nf):
        pos = i / ratio
        i0 = min(len(h_c) - 2, int(pos))
        w = pos - i0
        hf[i] = (1.0 - w) * h_c[i0] + w * h_c[i0 + 1]
    return hf


def run_multigrid_case(G: float, t_2048: float, dt_2048: float, t_4096: float, dt_4096: float):
    """Simulate 40 m (1024^2) -> 20 m (2048^2) -> 10 m (4096^2) bilinear prolongation smear."""
    T, U, A_in, z_c0, s0 = 50.0, 6.0e-4, 25.0e6, 0.0, 0.015
    h1, A1 = make_profile(63, 40.0, A_in, s0=s0)
    t = 0.0
    for _ in range(80):  # 80 * 1,000 yr (coarse evolution at dx=40 m)
        K1 = eval_lith_k(h1, z_c0 + U * t, T, False)
        h1, _ = step_fastscape_sd_1d(h1, A1, K1, U, 40.0, 1000.0, G)
        t += 1000.0

    h2 = upsample_linear_1d(h1, 40.0, 20.0)
    N2 = len(h2)
    A2 = [A_in + (N2 - 1 - i) * 5.0 * 400.0 for i in range(N2)]
    for _ in range(int(round(t_2048 / dt_2048))):
        K2 = eval_lith_k(h2, z_c0 + U * t, T, False)
        h2, _ = step_fastscape_sd_1d(h2, A2, K2, U, 20.0, dt_2048, G)
        t += dt_2048

    h3 = upsample_linear_1d(h2, 20.0, 10.0)
    N3 = len(h3)
    A3 = [A_in + (N3 - 1 - i) * 5.0 * 100.0 for i in range(N3)]
    res_up = inspect_detector(h3, eval_lith_k(h3, z_c0 + U * t, T, False), 10.0)

    for _ in range(int(round(t_4096 / dt_4096))):

        h3, _ = step_fastscape_sd_1d(h3, A3, K3, U, 10.0, dt_4096, G)
        t += dt_4096
    res_end = inspect_detector(h3, eval_lith_k(h3, z_c0 + U * t, T, False), 10.0)
    return res_up, res_end
```
