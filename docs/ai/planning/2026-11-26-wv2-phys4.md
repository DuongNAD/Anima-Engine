Direct inspection of `S2_6` (`4096²`) and `Q34` (`1024²`) spilled layers motivates a staged Phase-1 -> Phase-2 approach:

2. **`G-SHAPE.5.ValleysFlint` (`b_down = 1.304 -> [1.60, 3.50]`, `vf_down = 0.758 -> >= 1.50`, `vf_ratio = 1.31 -> >= 2.5`):**

3. **`G-SHAPE.3.DrainageDensity` (`caprock_tile_cv = 0.753 -> <= 0.45`, keeping `Dd`, `dis`, `endo_humid == 0.0`):**
   - *Diagnosis:* Of `16` qualifying `200×200` `SandstoneCaprock` tiles on `S2_6` (`4096²`), `15` lie on the eastern plateau with `dd` spanning `0.070` (`tile(13,18)` `h=1,351 m`) to `1.893` (`tile(2,18)`), while `1` humid western piedmont tile (`tile(8,10)`, `h = 290.6 m`, `P = 2.82`, `dd = 2.828`) sits inside the lower windward stratigraphic caprock band (`0 <= z_rel < 150 m`).
