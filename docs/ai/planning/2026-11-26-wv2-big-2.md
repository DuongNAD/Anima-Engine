## 1. Summary of Changes

1. **Separate `81.92 km` Verifier Profile (`WB-D3`, [verify/mod.rs](../../../src-tauri/crates/anima-worldgen/src/verify/mod.rs), [g_shape.rs](../../../src-tauri/crates/anima-worldgen/src/verify/g_shape.rs), [g_comp.rs](../../../src-tauri/crates/anima-worldgen/src/verify/g_comp.rs)):**
   - Added `VerifierProfileKind` (`"40.96km"` | `"81.92km"`) and `VerifierProfile`, selected automatically via `VerifierProfile::for_extent_m(meta.extent_m)` (`extent_m >= 80_000.0 => Large82Km`, otherwise `Standard40Km`).
   - Added `verifier_profile: Option<VerifierProfileKind>` to `VerificationReport` and explicit `verify_raw_dir_with_profile`, `evaluate_g_shape_with_flint_max`, `evaluate_c4_c5_and_flags_with_profile`, and `finalize_g_comp_v2_with_profile` entry points while leaving all legacy `40.96 km` helper signatures untouched.
   - `Standard40Km` preserves every trunk `40.96 km @ 10 m` rule byte-for-byte.
   - `Large82Km` encodes the `WV2-D2 §5` (`WB-D3` / `WB-D8`) ranges (table below).

2. **`C5b.CoastalPlainProfile` (`WB-D8`, [g_comp.rs](../../../src-tauri/crates/anima-worldgen/src/verify/g_comp.rs)):**
   - Evaluates 4-connected subaerial coastline cells belonging to landmass components reaching `>= 100 m` elevation (falling back to all coastline cells only if no component reaches `100 m`), excluding low `< 100 m` offshore islets so barrier islets cannot falsely inflate coastal-plain fractions (`excluded_low_islet_coast_cells` reported explicitly).
   - Computes exact $O(N)$ separable 2D Euclidean Distance Transform (`edt_1d_squared`, double-precision lower parabolic envelope intersection over one reused `Vec<f32>` grid buffer) from coastline cells to `h >= 100 m` and `h >= 1,000 m`.
   - Emits `C5bCoastalPlainProfileReport` as report-only (`gated: false`) under `40.96km` (leaving `overall_pass` and `failed_gates` unchanged) and gates `G-COMP-v2.C5b.CoastalPlainProfile` under `81.92km` (`gated: true`): `plain_backed_5km_fraction >= 0.60`, `plain_backed_3km_fraction >= 0.75`, `median_coast_to_1000m_km >= 10.0`, `steep_mountain_front_fraction (< 4.0 km) <= 0.20`, paired with `C5` `steep_cliff_fraction <= 0.25`.

3. **Scale-Aware `dx_m = 20.0 m` / `extent_m = 81,920 m` Hydrology & Karst Scaling ([lakes_falls.rs](../../../src-tauri/crates/anima-worldgen/src/lakes_falls.rs), [pipeline.rs](../../../src-tauri/crates/anima-worldgen/src/pipeline.rs)):**
   - Added `scaled_waterfall_max_run_m(dx_m)` (`30.0 m` below `20 m`; `max(30.0, 3.65 * dx_m)` = `73.0 m` at `20 m`) and `LakesFallsConfig::for_scale(dx_m, extent_m)` (`waterfall_max_count = 160` at `>= 80_000 m`, `80` below). `LakesFallsConfig::default()` stays unchanged.
   - Updated `pipeline.rs` (`apply_caprock_knickpoint_sapping`, `apply_late_quaternary_piedmont_subsidence`, `widen_trunk_alluvial_floodplains`, `s4_cfg`, `s6_cfg`, `s9_cfg`) strictly under `extent_m >= 80_000.0` so `< 80_000 m / 10 m` execution stays bit-identical at every multigrid level (`512`, `1024`, `2048`, `4096`).
