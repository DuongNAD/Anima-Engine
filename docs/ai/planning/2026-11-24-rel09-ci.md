# Card D2 (`REL09-CI`) — Release Build CI Workflow Note

## Scope & Design

- **Workflow file:** [`.github/workflows/release-build.yml`](../../../.github/workflows/release-build.yml)
- **Triggers:** `workflow_dispatch` and `pull_request` filtered to `paths: ['.github/workflows/release-build.yml']` so edits to the workflow prove both installers build on CI without running release builds on unrelated PRs.
- **Security & permissions:**
  - `permissions: contents: read` only.
  - Zero secrets, zero code signing, zero `pull_request_target`, zero `gh release`, and no upload targets other than `actions/upload-artifact` with `retention-days: 14`.
  - Every third-party action is pinned to a full commit SHA with its tag in a trailing comment (`actions/checkout`, `actions/setup-node`, `Swatinem/rust-cache`, `actions/upload-artifact`).
- **Build configuration:**
  - Runs separate `windows-latest` and `macos-latest` jobs (`timeout-minutes: 120`).
  - Installs the pinned Rust toolchain from [`rust-toolchain.toml`](../../../rust-toolchain.toml) (`rustup toolchain install`) and Node `'22'` matching [`.github/workflows/ci.yml`](../../../.github/workflows/ci.yml).
  - Reuses `ci.yml`'s `Swatinem/rust-cache` configuration (`workspaces: src-tauri`, `add-rust-environment-hash-key: false`, `key: toolchain-${{ hashFiles('rust-toolchain.toml') }}`, `save-if` on `main` and `feat/ecological-selection`).
  - Runs `npm ci` and `npm run tauri:build` (which passes `--features desktop`, never bare `tauri build`), using existing [`src-tauri/tauri.conf.json`](../../../src-tauri/tauri.conf.json) and [`package.json`](../../../package.json) untouched.
- **Uploaded artifacts (`retention-days: 14`, `if-no-files-found: error`):**
  - `anima-engine-windows-installers`: `src-tauri/target/release/bundle/msi/*.msi` and `src-tauri/target/release/bundle/nsis/*.exe`.
  - `anima-engine-macos-bundles`: `src-tauri/target/release/bundle/dmg/*.dmg` and `src-tauri/target/release/bundle/macos/*.app`.
