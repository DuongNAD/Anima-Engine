## Key Design Decisions Implemented

- **`ANMW v3` Codec & Projection (`anima-worldgen`):** Added `src-tauri/crates/anima-worldgen/src/anmw_v3.rs` behind the `reader` feature so `anima-engine` decodes `ANMW v3` `sim_256.anmw3` payloads without pulling `generate` or `bake` dependencies.
- **`Copy`-Safe Dual World Pinning (`LD-2`):** Added `WorldIdentity::sim_world_sha256: Option<[u8; 32]>` (`Copy`, omitted from JSON when `None`, custom `opt_sha256_hex` codec) across all 14 `WorldIdentity { ... }` literal sites on `ba344ea` plus the 15th site added by `#236` (`world_record_format_and_immutability_tests.rs:26`), along with `terrain_map_from_v3_sim` and `mismatch_against` checks.
- **Pre-Switchover Experiment & Manifest Isolation (`Option B1`):** `ExperimentManifest::fingerprint()` mixes `sim_world_sha256` (`c.tag(0xF8)` + 4 `u64::from_le_bytes` chunks) only when `Some`, remaining byte-identical to trunk when `None`. Verified non-constantly on `baseline-no-exotic.json` in `wv2_3_manifest_fingerprint_is_legacy_identical_when_sha_none_and_sensitive_when_some`.
- **Loud Pre-Switchover `ANMW v3` Refusal:** `WorldArtifact::peek_seed`, `WorldArtifact::from_bytes`, `try_world_seed_from_disk`, `world_seed_from_disk()` (`world_artifact.rs`), and `load_shared_world_artifact` (`ecs.rs`) refuse/panic loudly on `ANMW v3` headers before `WV2-7` while preserving `"unsupported artifact version"` + `"regenerate"` substrings required by `world_artifact_adversarial_tests`.
- **G2 Feature-Separation Tree Gate (`MSG_20261124_023500` Option A1):** Empirical check on clean trunk (`ba344ea`) showed `anima-engine` already carries `toml v1.1.3+spec-1.1.0` (via `cubecl-environment` / `tauri-utils`) and `toml_edit v0.21.1` (via `bevy_macro_utils` / `bevy_ecs`), while `anima-worldgen --features generate` uniquely introduces `toml v0.8.23` and `toml_edit v0.22.27`. Updated `.github/workflows/ci.yml` (`:140`, `:143`) to query `cargo tree ... --format '{p} [{f}]'` for both `(generate|bake)` feature flags on `anima-worldgen` and `toml v0\.8\.|toml_edit v0\.22\.`, and updated `feature_separation_engine.patch` + `gate_controls.mjs` (`:1228`) fault injection accordingly.
