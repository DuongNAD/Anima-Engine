# Card `WV2-4` — `G-SHAPE` + `G-COMP v2` Verifier & Pre-Registered Calibration

## 1. Implementation Scope

Implements `WV2-4` (Card 5 of [the World v2 design](../design/2026-11-20-world-v2-design.md)) inside [`anima-worldgen`](../../../src-tauri/crates/anima-worldgen/Cargo.toml) (`b6b5b6c6`):

- `src/verify/g_shape.rs`: evaluates all 7 `G-SHAPE` quantitative metrics (§4.1) and shoreline fractal dimension $D_{\text{shore}}$ (§4.2) on both spilled `--raw` layers and standalone `--dem-input` `.f32` grids.
- `src/verify/g_comp.rs`: evaluates `G-COMP v2` gates `C1..C5` (§5.1) sequentially in memory so `4096²` verification stays well within local memory limits.
- `src/verify/mod.rs`: orchestrates sequential `G-SHAPE` + `G-COMP v2` + `G-SIM` raw (`GS-1` / static `GS-2`) verification, writes `gates.json`, and emits `sim_256.anmw3` + canonical sorted-key `index.json`.
- `src/bin/anima-worldgen.rs`: adds `verify` (`--raw` and `--dem-input`, `--out-gates` / `--report`, `--out-sim`, `--out-index`, `--strict-gates`, `--report-only`) and makes `generate` default `seed` and `grid_size` from `--preset` TOML when omitted on the CLI (CLI flags still override).
- `tests/wv2_4_g_shape_comp_tests.rs` & [`scripts/test_target_policy.mjs`](../../../scripts/test_target_policy.mjs): adds all 4 planted Card 5 negative controls (parallel-comb DEM, cratered/spiky DEM, inverted valley DEM, uniform/Steppe biome matrix) plus CLI end-to-end preset/tamper checks, registered under `required-features = ["generate"]`.

## 2. Pre-Registered Calibration Candidates & Selection Rule (Committed Before Measuring)

**Strict No-Loosening Rule (`MAP-D3`):** No threshold in `G-SHAPE` (§4.1–§4.2), `G-COMP v2` (§5.1), or `G-SIM` (§5.2) may be modified or relaxed during or after calibration. If no candidate passes all 15 verification gates (`8` `G-SHAPE` + `5` `G-COMP v2` + `2` `G-SIM` raw checks) at `4096²`, `artifacts/world-v2/` is **not** committed as passing and the card stops transparently at `GATE, BLOCKED` with observed Stage-1/Stage-2 measurements.

### 2.2 Deterministic 5-Level Selection Rule

1. **Level 1 (`overall_pass`):** Prefer candidates with `overall_pass == true` (all 15 gates pass).
2. **Level 2 (`passed_gate_count`):** Higher count of passing gates out of `15` (`8` `G-SHAPE` + `5` `G-COMP v2` + `2` `G-SIM` raw checks).
3. **Level 3 (Hard Invariants):** Prefer `G-SIM` passing AND zero unmodeled micro-pits, zero severed humid spillways, zero non-cliff needle spikes, and `0` cells in `Chaparral`/`Steppe`.
4. **Level 4 (Coverage & Shortfall Tie-Break):** Higher `zoned_16_biomes_passing` count (`0..=16`), then lower sum of relative shortfalls on failing numeric gate bounds.
5. **Level 5 (Deterministic Tie-Break):** Lowest pre-registered candidate ID (`C01 < C02 < ... < C08`).

**Stage-2 Promotion:** Promote the top `2` ranked Stage-1 (`1024²`) candidates verbatim (preserving seed and preset parameters, setting `grid_size = 4096`) to full `4096²` generation + verification, recording wall time and peak RSS. Official `artifacts/world-v2/{preset_v2.toml,sim_256.anmw3,index.json,gates.json}` is written only if the top Stage-2 (`4096²`) candidate passes `15/15` gates (`overall_pass == true`).
