# Card `WV2-1c` — `Fastscape-SD` Solver Hardening

## Summary

`WV2-1c` closes the three non-blocking solver notes carried from `WV2-1b r1` (`verdicts/WV2-1b_b9fd3935.md` `N1`, `N2`, `N5`) cleanly within [`anima-worldgen`](../../../src-tauri/crates/anima-worldgen/Cargo.toml):

1. **Hybrid Two-Phase Gauss–Seidel (`src/erosion_fluvial.rs`):**
   - **Phase A (fast path):** Attempts the `r0` two-sweep receiver-first Gauss–Seidel at full `dt_yr` (`substeps = 1`, `used_fallback_order = false`), restoring single-pass humid performance without sub-stepping.
   - **Phase B (robust fallback):** Only when Phase A fails to converge within `max_gs_iters` (and sweep budget permits) does `step_fastscape_sd_dag` fall back to `r1`'s in-place upstream-to-downstream Gauss–Seidel `(D + U) h^(r) = b - L h^(r-1)` with adaptive `Δt` halving (`used_fallback_order = true`).
   - Added `pub used_fallback_order: bool` to `FluvialStepStats`.
2. **Convergence & Overflow Bounds (`src/erosion_fluvial.rs`):**
   - Validated `params.max_dt_halvings <= MAX_ALLOWED_DT_HALVINGS` (`12`, capping sub-steps at `4,096` and preventing `1_usize << halving` overflow for `>= 64`).
   - Added `pub max_total_sweeps: usize` (`Default`: `DEFAULT_MAX_TOTAL_SWEEPS = 4_096`) and validated `max_total_sweeps > 0`, tracking `sweeps_spent` across Phase A + Phase B so unrecoverable failure aborts cleanly in minutes rather than hours without mutating `h` (`FluvialError::NonConvergence { ..., total_sweeps, budget_exhausted }`).
3. **Independent `512²` Residual Check (`tests/wv2_1b_solver_hydro_tests.rs`):**
   - Added `independent_implicit_residual` walking `d8_receiver` in test code (no shared solver helpers) and replaced the loose `2,050 m` delta bound on the `512²` dry-zone (`nu = 0.15`, `PET = 1.0`, `dt ∈ {1 kyr, 10 kyr, 100 kyr}`) with manual sub-step replay (`< 1e-12 m` discrepancy) plus implicit residual `< 1e-5 m`, alongside humid `512²` (`nu ∈ {1.0, 2.0}`) Phase A fast-path assertions (`!used_fallback_order && substeps == 1`) and `< 1e-5 m` residual checks.
4. **Measured `4096²` Release Single-Step Timings (Apple MacBook Air M5, `--release`, Measurements Only):**
   - **`WV2-1b r1` (`b9fd3935`, always upstream-first):** `s1 = 0.566 s`, `priority_flood_d8 = 2.122 s`, `fastscape_sd_g085 = 58.352 s` (`gs_iters = 30`, `substeps = 8`).
   - **`WV2-1c` (`Phase A` receiver-first fast path):** `s1 = 0.598 s`, `priority_flood_d8 = 2.098 s`, `fastscape_sd_g085 = 3.704 s` (`gs_iters = 14`, `substeps = 1`, `total_sweeps = 14`, `used_fallback = false`) — `~15.8×` speedup on the humid `4096²` step.
