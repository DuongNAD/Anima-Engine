# Card `WV2-1a` — `anima-worldgen` Crate Scaffold & Stage `S1` Tectonics

## Summary

`WV2-1a` introduces the standalone workspace member crate [`anima-worldgen`](../../../src-tauri/crates/anima-worldgen/Cargo.toml) under `src-tauri/crates/anima-worldgen/` while keeping `src-tauri/Cargo.toml` (`anima-engine`) and `src-tauri/src/` completely decoupled (`0` added default dependencies).

### Implemented Scope

1. **Crate boundary & G2 feature contract (`src-tauri/crates/anima-worldgen/Cargo.toml`):**
   - Features `default = []`, `reader = ["dep:sha2"]`, `generate = ["reader", "dep:libm", "dep:rand", "dep:rand_chacha", "dep:rayon", "dep:serde"]`, and `bake = ["generate"]` (stub ready for `WV2-5`).
   - Integration test `[[test]] name = "wv2_1a_tectonic_tests"` gated on `required-features = ["generate"]` matching crate-level `#![cfg(feature = "generate")]`.
   - Every dependency resolves against pinned versions already present in `src-tauri/Cargo.lock` (`sha2`, `libm`, `rand`, `rand_chacha`, `rayon`, `serde`).
2. **Determinism guardrails (`clippy.toml`, `src/lib.rs`, `src/rng.rs`):**
   - `clippy.toml` configures `disallowed-methods` banning std `f32`/`f64` transcendental methods (`sin`, `cos`, `tan`, `asin`, `acos`, `atan`, `atan2`, `sinh`, `cosh`, `tanh`, `exp`, `exp2`, `exp_m1`, `ln`, `ln_1p`, `log`, `log2`, `log10`, `powf`, `powi`, `cbrt`, `hypot`, `sin_cos`) in favor of `libm`, enforced with `#![deny(clippy::disallowed_methods)]`.
   - Domain-separated `ChaCha12Rng` derivation (`SHA-256("ANIMA-WV2" || seed || width || height || schema_tag || stage_tag)` and per-cell `(row, col)` seeding) in `src/rng.rs`.
3. **Config & Stage `S1` Regional Coastal Massif (`src/config.rs`, `src/tectonic.rs`):**
   - `WorldV2Config` validates grid resolution (`>= 64`, even), `40.96 km` domain extent, `[-1,500 m, +5,700 m]` vertical bounds, `target_ocean_fraction ∈ [0.40, 0.50]`, caprock strata `[450, 1100] m`, and `<= 8.0×` erodibility contrast.
   - `generate_uplift` synthesizes the asymmetric coastal mountain spine, deep oceanward continental slope, structural rift valley, leeward sandstone caprock tableland, collapsed volcanic stratocone caldera, deterministic quantile sea-level shift, and 6-class lithology (`GraniteCrystalline`, `SandstoneCaprock`, `SolubleLimestone`, `BasaltVolcanic`, `SoftShale`, `UnconsolidatedAlluvium`) using `libm` + row-parallel `rayon`.
4. **CI, G2 & Test-Target Policy Gates:**
   - Added `cargo clippy -p anima-worldgen --all-targets --features reader,generate,bake -- -D warnings`, extended `cargo tree` G2 checks (`--no-default-features`, `-p anima-engine`, `-p anima-worldgen --features reader,generate,bake`), and added `cargo test -p anima-worldgen --features "reader,generate,bake"` piped into `check_test_targets.mjs --profile worldgen-cpu` in [`.github/workflows/ci.yml`](../../../.github/workflows/ci.yml).
   - Registered `doc-tests:anima_worldgen`, `tests/wv2_1a_tectonic_tests.rs` (`generate`), and `worldgen-cpu` profile in [`scripts/test_target_policy.mjs`](../../../scripts/test_target_policy.mjs) & [`scripts/check_test_targets.mjs`](../../../scripts/check_test_targets.mjs), and extended [`src-tauri/tests/feature_gated_targets_tests.rs`](../../../src-tauri/tests/feature_gated_targets_tests.rs) to enforce manifest/source parity across both `src-tauri` and `crates/anima-worldgen`.
   - `tests/wv2_1a_tectonic_tests.rs` compares 1-thread vs. 4-thread `rayon` on the same machine (`single_vs_multi_thread_rayon_invariance`) without pinning any hardcoded checksum.
