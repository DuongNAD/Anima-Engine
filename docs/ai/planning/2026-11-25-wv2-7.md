# Card `WV2-7` — Desktop Switchover onto Bundled `sim_256.anmw3`

## 1. Plain Disclosure: Simulation Is World v2, Screen Is Still v1 Until `WV2-6`

**This card switches the Rust desktop simulation backend onto World v2 (`artifacts/world-v2/sim_256.anmw3`); it does NOT change the Three.js viewer.** Until `WV2-6` merges, the desktop frontend still renders the legacy `worldGen.ts` v1 map while the backend simulation runs on World v2 `C01` (`sim_world_identity = cbdd3ba9f57725ada233d1b43f2f5804fe8cb0fe0b098ca5ef8ae0aae5784c4d`).

Additionally, under [`MAP-D5`](../how-to/AGENT_WORKFLOW.md), committed [`artifacts/world-v2/sim_256.anmw3`](../../../artifacts/world-v2/sim_256.anmw3) is provisional `C01` reproduced from `#249` (`f195a361`), **not** post-`#270` (`WV2-PHYS2`) terrain (`preset_v2.toml` on trunk does not reproduce `C01`). `WV2-PHYS3` (`PR #274`) iterates physics separately; `WV2-7` loads whatever `sim_256.anmw3` and `index.json` are committed under `artifacts/world-v2/`.

## 2. Architecture & Precedence Contract

1. **Tauri static `bundle.resources` ([`tauri.conf.json`](../../../src-tauri/tauri.conf.json)):** Declares only the two committed files in Tauri v2 map form (`../artifacts/world-v2/sim_256.anmw3` -> `world-v2/sim_256.anmw3`, `../artifacts/world-v2/index.json` -> `world-v2/index.json`), so `tauri_build::build()` succeeds offline and in CI without fetched tile archives.
2. **Main-thread resource handoff ([`lib.rs`](../../../src-tauri/src/lib.rs)):** In `.setup(..)`, resolves `app.path().resource_dir()?.join("world-v2").join("sim_256.anmw3")` and passes it to [`SimulationEngine::set_bundled_world_path`](../../../src-tauri/src/core/simulation_loop.rs) before any save resume or worker spawn (`ANIMA_AUTOSTART` / `load_simulation_state`).
3. **Desktop loading precedence ([`world_artifact.rs`](../../../src-tauri/src/core/world_artifact.rs), [`ecs.rs`](../../../src-tauri/src/core/ecs.rs)):**
   - **Priority 1 (`ANIMA_WORLD_ARTIFACT` set):** Reads the explicit file (loud `Err` on missing/unreadable; zero fallback). If its header is `ANMW v3`, verifies its SHA-256 against `index.json` `sim_world_identity` (sibling `index.json`, bundled `index.json`, or dev `artifacts/world-v2/index.json`), returning a loud `Err` naming `"ANMW v3"` on any mismatch or missing `index.json`, otherwise decodes `AnmwV3Sim` (`sim_world_sha256 = Some(..)`, `WorldV3SeaLevel(sea_level_norm)`). If it is a legacy `ANMW v2` `.anmw` file (e.g., `world_real_128.anmw` or `world_4x4.anmw`), `WorldArtifact::from_bytes` decodes it cleanly (`sim_world_sha256 = None`, no `WorldV3SeaLevel`).
   - **Priority 2 (`ANIMA_WORLD_ARTIFACT` unset, bundled resource path present):** Loads `world-v2/sim_256.anmw3` verified by SHA-256 against sibling `world-v2/index.json` `sim_world_identity`.
   - **Priority 3 (`ANIMA_WORLD_ARTIFACT` unset, dev / headless desktop test without bundle dir):** Resolves committed `artifacts/world-v2/sim_256.anmw3` and verifies its SHA-256 against `artifacts/world-v2/index.json` `sim_world_identity` (`cbdd3ba9f57725ada233d1b43f2f5804fe8cb0fe0b098ca5ef8ae0aae5784c4d`).
   - **Legacy v1 temp artifact retired:** `<temp_dir>/anima_world_artifact.anmw` (written by `save_world_artifact`) is **no longer read in desktop mode** (`TerrainSource::AppArtifactOrGenerated`). No procedural noise or `anima_world_cache` fallback exists on the desktop path; any missing, corrupt, or SHA-mismatched `sim_256.anmw3` returns a loud `Err` / panic.
4. **Refusing old/mismatched saves loudly (`load_simulation_state` `(4b)` + engine backstop):**
   - [`load_simulation_state`](../../../src-tauri/src/commands/simulation.rs) resolves `active_desktop_world_identity` after `snapshot::read` and **before** calling `engine.stop()`, returning `Err(reason)` from `WorldIdentity::mismatch_against` and leaving any running simulation undisturbed.
   - [`start_from_manifest_with_engine`](../../../src-tauri/src/commands/simulation.rs#L963-L991) clears `pending_load_state = None` before calling `engine.start`, so it carries no stale snapshot.
   - [`SimulationEngine::start`](../../../src-tauri/src/core/simulation_loop.rs) enforces an engine backstop **before** spawning learner/evolution/simulation threads: if `pending_load_state` mismatches the active world (`mismatch_against`), it logs `ERROR:` to `stderr`, discards the incompatible pending snapshot, resets `running = false`, and spawns `0` worker threads.
5. **Headless science unchanged:** `TerrainSource::Generated` (`LiveExperimentAdapter`) keeps procedural `MapSettings::default()` + `MapConfig::default()` (`sim_world_sha256 = None`, no `WorldV3SeaLevel`). When `pending_manifest` is queued without `ANIMA_WORLD_ARTIFACT`, `SimulationEngine::start` keeps `Generated` for viewer manifest parity (`SEL2-P` / `start_from_manifest_tests.rs`).

## 3. Lake-Threshold Audit (`simulation_loop.rs`)

Line `simulation_loop.rs:1754` previously filtered non-`land_nav` lake spawn candidates with `(biome == 0 || biome == 1 || biome == 3) && elevation < 0.4` (`< 1,380 m` in `ANMW v3`). Extracting `is_non_land_nav_lake_candidate(biome, elevation, v3_sea_level_norm)` switches **only the v3 path** (`WorldV3SeaLevel` inserted from `ANMW v3`) to `(biome == 1 || biome == 3) && elevation > sea_level_norm + 0.001` (`> 1.38 m` above sea level), while leaving v1 / `Generated` (`None`) bit-identical.

Measured on committed `C01` [`sim_256.anmw3`](../../../artifacts/world-v2/sim_256.anmw3) (`65,536` cells, `sea_level_norm = 0.2083333`):
- **Before (v1 rule):** `29,467` candidates (`29,457` `biome_22 == 0` Ocean cells mapped to backend `Ocean = 1` + `10` `biome_22 == 14` Lake cells mapped to backend `Ocean = 1`; `0` alpine lakes `>= 0.4`), i.e., `99.97%` of candidates were ocean water.
- **After (v3 rule):** `10` candidates (all `10` inland freshwater lake cells at `elevation = 0.3418..0.3469 > 0.2093`; `0` Ocean cells; alpine lakes `>= 0.4` now remain eligible).
