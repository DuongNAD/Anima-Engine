## Implementation Summary
- **`sha256.ts` + `tileLoader.ts`:** Fetches `/artifacts/world-v2/index.json` and local tiles at `mip = 2` (`1024x1024`, `4x4` tiles per layer; `water_surface` absent-tile dry optimization respected). Verifies exact `byte_len` and WebCrypto `SHA-256` against `index.json` before decoding; throws `TileIntegrityError` loudly with zero fallback to v1.
- **`ktx2Decoder.ts`:** Pure-TS KTX2 v2.0 + ZLIB (`three/examples/jsm/libs/fflate.module.js`, zero new npm packages) + BC4/BC5 decoder for `R16_UNORM` (`height`), `BC5_UNORM` (`normal_xy`), `R8G8B8A8_SRGB` (`macro_albedo`), `R8G8B8A8_UNORM` (`biome_ids`, `biome_weights`, `terrain_lighting`), and `R16G16_UNORM` (`water_surface`), stripping the `2`-texel border gutter (`260 -> 256`).
- **`WorldV2TerrainMesh.tsx` + `WorldV2WaterMesh.tsx` + `WorldV2Banner.tsx`:** `512x512` displaced mesh with physical `1:1` elevation scale (`[-1500, +5700] m` over `40,960 m`), baked `normal_xy` shading, `macro_albedo` + biome palette + `terrain_lighting` AO texture, ocean + inland lakes/rivers (`water_surface`), and top-center `"World v2 Preview — not the simulated world"` banner.
