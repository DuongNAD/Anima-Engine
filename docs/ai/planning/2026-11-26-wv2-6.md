# `WV2-6` — Full World v2 Viewer (`2026-11-26`)

## Scope & Open Owner Gates

This card implements the full World v2 Three.js viewer, build-time tile prefetch script, `world_v2_manifest.json` evidence generator, and frontend tests as a **prototype** draft PR (`win/wv2-6`).

- **Open owner gate 1 (not executed here):** Public tile release (`~145 MB` C01 or replacement world tile pack on GitHub Releases). `scripts/fetch_world_v2_tiles.mjs` declares the release download URL as a named constant and supports `ANIMA_WORLD_V2_TILES_ARCHIVE` / `ANIMA_WORLD_V2_TILES_DIR` for local/offline staging; zero public uploads or tags are created.
- **Open owner gate 2 (not executed here):** Dell Intel Iris Xe before/after desktop FPS gate with `1,000` creatures at `Low` quality (`§7.2`, `<= 60` draw calls). Any FPS sanity check recorded from `DESKTOP-3EPV830` (`RTX 5060 Ti`) is explicitly labeled dev machine only and makes no claim about the Dell.
- **Tauri staging detail (`§3.3.2`, `QD-TRIAL-V3`):** `src-tauri/tauri.conf.json` edits only `build.beforeBundleCommand` (`"npm run fetch:world-v2-tiles"`) and leaves static `bundle.resources` (`sim_256.anmw3` and `index.json`) untouched. Tiles are staged into gitignored `/public/world-v2/` so Vite dev and `tauri build` (`frontendDist: "../dist"`) serve `/world-v2/*` with zero runtime network fetches, zero CSP changes, and zero IPC changes. Because `vite build` runs in `beforeBuildCommand`, running `npm run fetch:world-v2-tiles` before `npm run tauri:build` (or via `beforeBundleCommand` when bundling) keeps `public/world-v2/` populated for packaged builds while clean CI checkouts keep `public/world-v2/` absent.
- **Prototype choices:** Default quality-tier mip selection uses `L2` (`1024²`) on `low`/`medium` and `L1` (`2048²`) on `high` (with `?wv2Mip=0..4` override), loading `macro_albedo` at `L2` (`1024²`, its highest baked mip in `index.json`) when `mip < 2`. Software `RG8` height packing and `RGBA8` BC5 normal decoding provide full WebGL2 fallback when `EXT_texture_norm16` or `EXT_texture_compression_rgtc` is absent.

## Untouched Invariants & Negative Controls

- **No silent fallback:** Missing or corrupted `/world-v2/` assets surface `WorldV2ErrorPanel` loudly and never fall back to v1 `worldGen.ts`.
- **Zero v1 generation / IPC artifact writes in World v2 mode:** `worldGen.worker.ts`, `save_world_artifact`, and `computeHorizonAoMap` are never invoked.
- **Decorative isolation (`ADR-0010 §4`):** Baked `flora_tiles`, terrain lakes, and `cave_network.bin` / `cave_entrances` are behind the `§6` decorative toggle.
- **Negative controls:** `(a)` 1-byte tamper in any tile or `index.json` fails prefetch and loader with `TileIntegrityError`; `(b)` stale `world_v2_manifest.json` fails `worldV2ManifestEvidence.test.ts` while `mapManifestEvidence.test.ts` stays green.
