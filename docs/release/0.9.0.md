## 4. Known Limitations

- **Unsigned binaries & no auto-updater:** Both Windows SmartScreen and macOS Gatekeeper warn on first launch (`QD-M8` open); no automatic update or crash-telemetry channel exists.
- **Single-machine scope:** `0.9` is single-machine only (`QD-1 = level 2`); multi-machine networking / federation belongs to Stage 7 (after `v1.0.0`).
- **Desktop runtime weight & unmeasured 1,000-agent release app target:** The full Bevy/Tauri desktop app is heavy (`CLAUDE.md` Gotchas); a full 1,000-agent release desktop run (`H6`/`H7`) has not yet been recorded in [`STATE_OF_THE_PROJECT.md` §1](../planning/STATE_OF_THE_PROJECT.md#1-bảng-bằng-chứng-có-thẩm-quyền).
- **Cross-OS numerical divergence:** Deterministic mode guarantees bit-exact replay on the same OS family and build (`DETERMINISM_CONTRACT.md`); `M1` (`#100`, `#102`) measured 1-ULP `libm` differences across OS families.
- **3D background fauna & caves are visual decoration:** Fish, birds, background wildlife, and caves carry `"Decoration, not simulated"` labels until Stage 6+ realm ADRs (`QD-REALMS`).
- **World v2 (`anima-worldgen`) & v1.0 morphogenesis deferred:** `DevelopedPhenotype` (ADR-0001) and live `DynamicFields` schedule integration are planned for v1.0 (`V0–V11`), and World v2 tiled artifacts are not yet loaded by the desktop app (`WV2-6`/`WV2-7`).
- **Open legal note (`utf8-chars` `3.0.7`):** As documented in [`licensing/UNRESOLVED.md`](../../licensing/UNRESOLVED.md#closed-by-electing-apache-20), `utf8-chars` carries no licence file upstream; the project elected `Apache-2.0` under its Cargo `MIT OR Apache-2.0` declaration (`QD-C2`, `#175`), noting that treating a bare Cargo `license` field as an author grant is an engineering record, not legal advice.
