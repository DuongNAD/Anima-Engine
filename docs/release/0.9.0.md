# Anima Engine 0.9.0 — Draft Release Notes

> **Status: `proposed` (draft).** No `v0.9.0` tag, release candidate, or public installer has been cut yet. Per owner decision `QD-1 = level 2` ([`AGENT_WORKFLOW.md` §4](../how-to/AGENT_WORKFLOW.md#4-khối-decisions-để-dán-vào-prompt-0)) and Stage 5 of the [Direction & Coordination Plan §5](../planning/DIRECTION_AND_COORDINATION_PLAN_2026-11-13.md#5-lộ-trình-theo-chặng), `0.9` is a **single-machine** pre-1.0 release. Under **`QD-FOCUS FOCUS-1`** (`#314`, trunk `f684049d`), `0.9` is under a **hard scope freeze** until `v0.9.0` is tagged: only bug fixes, the `0.9` release path (`FOCUS-2`), `SEL2-P2` / `REPLAY-1` (`FOCUS-3`), and measurement/decision docs advance; multi-machine worlds (`Stage 7`) and v1.0 / living-world feature cards remain deferred until after `v0.9.0` (`FOCUS-4`).

## 4. Known Limitations

- **Unsigned binaries & no auto-updater:** `0.9` installers ship unsigned (`QD-REL09` G2 / `QD-OPENC` `QD-M8` deferred before `v1.0.0`, `#255`), so SmartScreen and Gatekeeper warn on first launch and no automatic updater or crash-telemetry channel exists.
- **Single-machine scope & `0.9` scope freeze:** `0.9` is single-machine only (`QD-1 = level 2`); multi-machine networking / federation (`Stage 7`) and new living-world / ecosystem modules (`RESP-D`, `INVERT-D`, `AERO-D`, `AQUA-D`, `FOSS-D`, `WX-D`, `PATHO-D`, `MICRO-D`, `ADR-0015..0018`, `DevelopedPhenotype`, `DynamicFields`) are deferred until after `v0.9.0` (`QD-FOCUS FOCUS-1` / `FOCUS-4`, `#314`).
- **World v2 trunk transition & placeholder metadata:** On trunk `f684049d`, `WV2-7` (`#279`) boots `C01` in simulation while keeping legacy v1 rendering until `WV2-6` merges (`FOCUS-2` step 4); the target `v0.9.0` `81.92 km` (`4096² @ 20 m`) world awaits `WV2-BIG-HYDRO`, `WV2-BIG-FLORA`, and `WV2-BIG-3`, with final hashes (`world_sha256`, `sim_world_identity`, `release_archive_sha256`) and sizes **set at WV2-BIG-3** and the single public tile pack **about 190 MB, final size set at WV2-BIG-3**.
- **Trial population vs. unmeasured 1,000-agent desktop target:** Per `QD-SCALE-TRIAL` (`#255`), interactive trial/demo islands target **about `100` individual animals** (`~0.33 ms/tick` headless vs `5.64 ms/tick` at `1,000` agents); a full `1,000`-agent release desktop run (`H6`/`H7`) remains unrecorded and the Intel Iris Xe `WV2-6` hardware gate (`#289`) stays open prior to `v0.9.0-rc.1`.
- **Cross-OS numerical divergence:** Deterministic mode guarantees bit-exact replay on the same OS family and build (`DETERMINISM_CONTRACT.md`); `M1` (`#100`, `#102`) measured 1-ULP `libm` differences across OS families.
- **3D background fauna & caves are visual decoration:** Fish, birds, background wildlife, and caves carry `"Decoration, not simulated"` labels (`C14`, `#269`) until post-`0.9.0` realm work (`QD-REALMS`).
- **Open legal note (`utf8-chars` `3.0.7`):** As documented in [`licensing/UNRESOLVED.md`](../../licensing/UNRESOLVED.md#closed-by-electing-apache-20), `utf8-chars` carries no licence file upstream; the project elected `Apache-2.0` under its Cargo `MIT OR Apache-2.0` declaration (`QD-C2`, `#175`), noting that treating a bare Cargo `license` field as an author grant is an engineering record, not legal advice.
