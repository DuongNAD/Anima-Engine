# Anima Engine 0.9.0 — Draft Release Notes

> **Status: `proposed` (draft).** No `v0.9.0` tag, release candidate, or public installer has been cut yet. Per owner decision `QD-1 = level 2` ([`AGENT_WORKFLOW.md` §4](../how-to/AGENT_WORKFLOW.md#4-khối-decisions-để-dán-vào-prompt-0)) and Stage 5 of the [Direction & Coordination Plan §5](../planning/DIRECTION_AND_COORDINATION_PLAN_2026-11-13.md#5-lộ-trình-theo-chặng), `0.9` is a **single-machine** pre-1.0 release. Under **`QD-FOCUS FOCUS-1`** (`#314`, baseline extended through `#332` `8d58a580`), `0.9` is under a **hard scope freeze** until `v0.9.0` is tagged: only bug fixes, the `0.9` release path (`FOCUS-2`), `SEL2-P2` / `REPLAY-1` (`FOCUS-3`), and measurement/decision docs advance; multi-machine worlds (`Stage 7`) and v1.0 / living-world feature cards remain deferred until after `v0.9.0` (`FOCUS-4`).

## 4. Known Limitations

- **Unsigned binaries & no auto-updater:** `0.9` installers ship unsigned (`QD-REL09` G2 / `QD-OPENC` `QD-M8` deferred before `v1.0.0`, `#255`), so SmartScreen and Gatekeeper warn on first launch and no automatic updater or crash-telemetry channel exists.
- **Single-machine scope & `0.9` scope freeze:** `0.9` is single-machine only (`QD-1 = level 2`); multi-machine networking / federation (`Stage 7`) and new living-world / ecosystem modules (`RESP-D`, `INVERT-D`, `AERO-D`, `AQUA-D`, `FOSS-D`, `WX-D`, `PATHO-D`, `MICRO-D`, `ADR-0015..0018`, `DevelopedPhenotype`, `DynamicFields`) are deferred until after `v0.9.0` (`QD-FOCUS FOCUS-1` / `FOCUS-4`, `#314`).
- **World v2 trunk transition & unpublished tile pack:** On trunk `8d58a580`, `WV2-BIG-3` (`#332`, `MAP-D8` `9/15`) replaced provisional `C01` (preset kept at `src-tauri/crates/anima-worldgen/presets/wv2_c01_40960.toml`, `288` B, SHA-256 `f460fa73…`) in desktop simulation with `BIG_4096_v2` (`world_sha256 = 01956959c751458d279a9e675046de5627fb6095e1451138c41d750a7f88d821`, `sim_world_identity = 1d3130054d6939425003817fccf78b284e34632b64b7443e5d6b380e60203e31`, `sim_256.anmw3` `1,445,892` B), while legacy v1 screen rendering stays active until `WV2-6` merges (`FOCUS-2` step 4). The `81.92 km` (`4096² @ 20 m`) release tile pack `world_v2_1d313005_tiles.tar.gz` (`190,071,986` B, SHA-256 `4fdad1df3acd6ad32075365e754fbb56e5c511ff01ebaa47ae14d9267c7d7d0f`, `3,817` entries / `3,560` `.ktx2` tiles) remains **unpublished, pending the owner's release gate** (`FOCUS-2` step 3).
- **Trial population vs. measured `1,000`-creature Dell Iris Xe gate:** Per `QD-SCALE-TRIAL` (`#255`), interactive trial/demo islands target **about `100` individual animals** (`~0.33 ms/tick` headless vs `5.64 ms/tick` at `1,000` agents); see the Dell Iris Xe `1,000`-creature measurements in [`2026-11-26-wv2-6-iris-xe-runbook.md` §6](../ai/planning/2026-11-26-wv2-6-iris-xe-runbook.md#6-owner-result-table-template).
- **Closing the window does not stop the simulation process yet:** After closing the app window, `anima-engine.exe` keeps running and consuming about one CPU core (`~20.65–24.92` CPU-s during `20 s` close waits, `124.12–300.69` CPU-s cumulative from launch; one orphaned instance ran about `45 minutes` / `2,780.83` CPU-s with no window, `MainWindowHandle = 0`). Evidence: hub `test_runs/anima-dell_IRISXE-RUN/`, `test_runs/anima-case_APP-EXIT.md`.
- **WebView2 memory use and frame stalls on Intel Iris Xe (`Low`, `1,000` creatures):** During `60 s` captures on the Dell Vostro 3530 (`16 GB` host RAM), one `msedgewebview2` process reached `4.35–4.65 GB` working set. Frame-time stalls of `1.8–2.1 s` (`1,781.9–2,133.2 ms` worst frame) occurred in the World v1 viewer (`B0`), while the World v2 viewer (`#291` `A1`) measured median `64.9 FPS` (`64.94 FPS`) and `p5` `24.6 FPS` (`24.57 FPS`). See [`2026-11-26-wv2-6-iris-xe-runbook.md` §6](../ai/planning/2026-11-26-wv2-6-iris-xe-runbook.md#6-owner-result-table-template).
- **Windows power mode affects CPU clock speed:** On the Dell Vostro 3530 (`i7-1355U`), Windows `Best Power Efficiency` held the CPU around `1.7 GHz`; switching AC power mode to `Balanced` restored turbo boost clocks (hub `test_runs/anima-dell_IRISXE-RUN/SUMMARY.md`, [`2026-11-26-wv2-6-iris-xe-runbook.md` §3.1](../ai/planning/2026-11-26-wv2-6-iris-xe-runbook.md#31-pre-flight-on-the-dell-agent_rulesmd-5)).
- **Hybrid-GPU laptops require explicit GPU selection:** On dual-GPU systems (e.g. Intel Iris Xe + NVIDIA GeForce MX550), verify that `anima-engine.exe` is assigned to the intended GPU in **Settings → Display → Graphics** (and inspect Task Manager's GPU engine column before measuring).
- **Cross-OS numerical divergence:** Deterministic mode guarantees bit-exact replay on the same OS family and build (`DETERMINISM_CONTRACT.md`); `M1` (`#100`, `#102`) measured 1-ULP `libm` differences across OS families.
- **3D background fauna & caves are visual decoration:** Fish, birds, background wildlife, and caves carry `"Decoration, not simulated"` labels (`C14`, `#269`) until post-`0.9.0` realm work (`QD-REALMS`).
- **Open legal note (`utf8-chars` `3.0.7`):** As documented in [`licensing/UNRESOLVED.md`](../../licensing/UNRESOLVED.md#closed-by-electing-apache-20), `utf8-chars` carries no licence file upstream; the project elected `Apache-2.0` under its Cargo `MIT OR Apache-2.0` declaration (`QD-C2`, `#175`), noting that treating a bare Cargo `license` field as an author grant is an engineering record, not legal advice.
